# 🛡️ CYBERGUARD X - AI Threat Intelligence Platform

CYBERGUARD X is a multi-signal cybersecurity and financial fraud prevention engine that detects phishing, quishing (QR threats), SMS scams, identity spoofing, and UPI fraud.

## 🚀 Quickstart

1. **Clone & Install Dependencies**
```bash
git clone https://github.com/your-org/cyberguard-x.git
cd cyberguard-x
pip install -r requirements.txt
```

2. **Run Server**
```bash
uvicorn main:app --reload
```

3. **Access API Docs & SOC Console**
- API Docs: http://localhost:8000/docs
- Health Check: http://localhost:8000/health
